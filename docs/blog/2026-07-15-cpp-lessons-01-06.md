## 各课真正留下的点

### 第 01 课：先能编译，再谈语法

- 程序从 `main` 开始；`-Wall -Wextra -Werror` 一开始就开。
- 空壳里的 `(void)x;` 只是消“未使用参数”警告，实现后要删掉。
- `1LL * n * (n + 1) / 2` 不是公式花活，是让乘法在 `long long` 里做，防 `int` 溢出。
- `assert` 在 `test_practice` 里：全对就安静，错了才叫。

### 第 02 课：类型陷阱和控制流

- 整数除法 `5/2 == 2`；要小数至少一侧是浮点，或 `static_cast<double>(a) / b`。
- `clamp`、`sign`、边界 `n < 1` 这类题，逼着先想特殊输入。
- 偶数求和我用了 `k(k+2)/4` 的闭式；和 `m=n/2; m*(m+1)` 等价，一个更巧，一个更直。
- 第一次挂测试是因为 `count_digits` 算了 `dig` 却 `return 0`，警告也变成错误。

### 第 03 课：引用到底改的是谁

- 值传递改副本；`int&` 改调用方；`const T&` 只读且少拷贝。
- `swap_int` 必须引用；`max_ref` 返回引用后，`r = 100` 会改到原来的变量。
- `mean` 返回 `double`：总和可以是整数，平均常常有小数，除法前要进浮点。
- `vector` 这节开始 downstream 用起来：`empty` / `size` / 范围 for。

### 第 04 课：下标、原地修改、第一次出现

- `find_first` 第一次写成“最后一次”，因为循环里不断覆盖 `pos`；应找到就 `return i`。
- `to_upper_ascii` 必须用 `char&` 才能改 string；只转 `a`–`z`。
- `int` 和 `size_t` 比较会触发 `-Werror=sign-compare`，用 `static_cast<int>(a.size())` 或 `size_t` 下标。
- `substr(pos)`：`pos == size()` 合法，得空串；`pos > size()` 才异常。这和 `s[size()]` 不是一回事。

### 第 05 课：指针先问能不能碰

- `&x` 取址，`*p` 解引用，`nullptr` 表示空。
- `if (!a || !b) return;`：空指针当假值，解引用前先判断。
- `index_of` 返回 `&a[i]`；返回的指针只在 vector 还活着、且没因扩容搬家前可靠。
- `strlen_c` 数到 `'\0'`；`nullptr` 返回 0。参数指针按值传，函数里 `++s` 不改调用方。

### 第 06 课：封装和不变量

- `struct` / `class` 语言上主要差默认访问；风格上：纯数据聚合常用 struct，有规矩要守常用 class。
- **不变量**：对象合法时必须始终成立的规则，例如余额 `>= 0`、分数分母 `!= 0`。靠 private + 构造/接口维护，不靠调用方自觉。
- `int manhattan() const` 里，后面的 `const` 表示**不修改当前对象**，和前面修饰返回值的 `const` 不是一回事。
- `int x{0}` 是花括号初始化；对 `int` 近似 `= 0`，但 `{}` 更防收窄（如 `int n{3.14}` 会直接编译失败）。

## 今天反复出现的编译/调试习惯

1. PowerShell 路径用 `C:\Users\...`，不要用 Git Bash 的 `/c/Users/...`。
2. 运行当前目录程序写 `.\test_practice.exe`。
3. `test_practice` 没输出通常是通过，不是没跑起来。
4. `-Werror` 会把“赋值未使用”“有符号比较”直接打死，逼着写干净。
